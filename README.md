## Анализ бразильского интернет-магазина Olist

Интерактивный дашборд в Power BI для анализа бразильского рынка электронной коммерции на основе открытого набора данных Olist Brazilian E-Commerce.
Цель проекта — изучить динамику продаж, эффективность доставки, поведение покупателей и уровень удовлетворённости клиентов.

## Инструменты и технологии

- **Power BI** — разработка интерактивного дашборда.
- **Power Query** — очистка и преобразование данных.
- **DAX** — создание мер и расчёт ключевых показателей.
- **Data Modeling** — построение модели данных и связей между таблицами.
- **Data Visualization** — визуализация и анализ данных.

## Источник данных

Olist Brazilian E-Commerce Public Dataset — открытый набор данных, размещённый на платформе Kaggle.

## Выполненные задачи

- Изучение и подготовка исходных данных.
- Очистка и преобразование данных.
- Построение модели данных.
- Создание вычисляемых мер с использованием DAX.
- Разработка интерактивных визуализаций и KPI.
- Анализ продаж, доставки, клиентского поведения и отзывов.
